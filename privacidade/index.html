Política de privacidade

Atualizada em 19 de outubro de 2026

Esta política explica como a EBENEZER SOLUCOES EM TI LTDA (CNPJ 34.849.367/0001-04) trata dados pessoais neste site e nos serviços que presta, conforme a Lei Geral de Proteção de Dados (Lei 13.709/2018).

Este site

O site é apenas informativo: não tem formulário, não usa cookies de rastreamento e não coleta dados pessoais. O provedor de hospedagem pode registrar dados técnicos de acesso (como endereço IP) para segurança.

Sistemas e aplicativos de clientes

Nos sistemas e aplicativos que desenvolvemos para clientes, o cliente é o controlador dos dados e a Ebenezer atua como operadora, tratando os dados só para prestar o serviço contratado. Cada aplicativo tem a sua própria política, como a do RC Vendas.
